A learning project with a sense of place

A little more room to find your Kerala.

Elsewhere is a growing travel-guide project built to make exploring Kerala feel thoughtful and personal: discover a place, learn a little about it, and shape a trip at your own pace.

Why Elsewhere exists

Built around curiosity.

The idea is simple: good travel planning starts with inspiration, but it should leave space for local context and real-world conditions. Elsewhere brings destination discovery, cultural notes and a practical itinerary into one small guide.

01 / The guide

Useful before you go

Explore nine destination guides with highlights, food ideas, local tips and references. The Culture page offers a respectful introduction to selected traditions, while reminding visitors to confirm current access and event details with local organisers.

02 / The planner

Your trip, your pace

Save places and organise them into a day-by-day plan. The planner supports notes, trip dates, sharing and calendar export; saved places and the itinerary stay in this browser unless you choose to share a link.

Learning by building

A BCA project, from idea to working site.

Built as a BCA learning project, Elsewhere is an opportunity to practise the full path from interface design to server behaviour—then test and improve it as real features are added.

Frontend

Accessible, responsive pages

HTML, CSS and JavaScript power the destination browser, interactive itinerary, Culture, About and Contact pages. The project focuses on clear navigation, keyboard access, mobile layouts and keeping user data local by default.

Backend

A small Python web service

A Python WSGI server serves the pages and destination images, and provides JSON endpoints for searching destinations and loading guide details. Automated tests cover routes, authentication behaviour, the catalog and static files.

A work in progress

Honest about what it is.

Elsewhere is an independent learning project, not an official tourism authority or booking service. Travel details can change; check current conditions, opening information and local guidance before you go.

It is still growing. Accounts, cloud-synced itineraries, bookings and a server-side contact form are not part of the current site.
